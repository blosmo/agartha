# Blender 5.2 runtime upgrade

The runtime and Linux CI now pin Blender 5.2.1 LTS. The download series derives from the version, and the worker locates the bundled Python site-packages directory rather than assuming Python 3.11. Official Linux archive verification passed during the Modal image build.

Compatibility changes:

- Use `BLENDER_EEVEE`, replacing the Blender 4.5 `BLENDER_EEVEE_NEXT` identifier.
- Set the encoder's image settings `media_type` to `VIDEO` before selecting FFmpeg output.
- Preserve historical asset provenance and earlier benchmark reports.

## Advanced modeling verification

`advanced_kit.py` provides editable arches, stairs and columns, connected SDF rock generation, Mesh Bevel nodes, and a shared typed bundle/closure finishing group. `baking.py` provides stone/wood procedural presets and a bounded, source-preserving PBR bake on evaluated meshes.

Real Blender checks cover dimensions, independent/atomic parameter edits, empty source meshes, actual closure and SDF evaluation, saved-source editability, and exported triangle counts. Five test objects export to 12,616 triangles. Baking checks cover effective Geometry Nodes materials, source UV preservation, one output UV map, packed color/metallic-roughness/normal maps, Edit mode, invalid shaders, and early/late failure cleanup.

The local combined example is generated by `scripts/blender/create_advanced_demo.py`: 9,150 triangles and an editable .blend, static GLB and PNG preview under `/tmp/agartha-advanced-demo`.
