# Managed Astra modeling

Approved product: Create a model is the default; Direct Blender remains an advanced interface. A brief and total USD budget authorize one bounded job using GPT-6 Astra to plan, build, inspect and refine. Model selection is absent from the primary flow.

## Execution and money

Reuse the existing private Blender broker and artifact retention. Reserve a fixed compute allowance and the remaining AI allowance atomically from the same wallet. Every AI request needs a durable, single-use cost reservation before dispatch. Bound request bytes, image dimensions and output tokens; no provider retries after ambiguous outcomes. Charge known usage, retain uncertain request cost pending reconciliation, and release unused funds at completion. Never exceed the approved total. Model output cannot increase budget, choose URLs, access credentials, or authorize payments.

Run a durable Modal job outside the untrusted Blender sandbox. Use a narrow authenticated Vercel AI proxy with its deployment OIDC identity. Keep model and rates pinned to the verified Gateway catalog. The proxy accepts only a claimed managed job operation, never arbitrary unauthenticated inference. Stop/cancel controls terminate further inference and settle Blender. Lost workers fail closed and release only unspent funds after outstanding operations expire.

## Delivery

An authenticated jobs API exposes state, actual charges, cancellation and private artifacts. The default page stores the user's existing stable identity locally, supports credit purchase, and starts only after explicit submission of the brief and total budget. Agent docs prefer jobs and retain direct sessions. No model quality guarantee; report whether previews were inspected and return partial usable files when budget expires.

## Verification

Test atomic holds, duplicate creates/dispatch, cross-owner access, concurrent cancellation, oversized model input, ambiguous provider outcomes, output costs, and partial exports. Run a capped synthetic live job before advertising availability. Deploy ledger, broker and gateway in dependency order; inspect public API and browser flow.

## Reference-guided jobs

See [the reference-guided workflow](design/reference-guided-modeling.md). An optional mode pins GPT Image 2.5 Flare for one design sheet, uses protocol 2 for explicit Blender MCP actions, and retains accepted checkpoints. Legacy jobs remain protocol-compatible. The reference feature is disabled unless `AGARTHA_REFERENCE_MODELING_ENABLED=true` or an explicitly configured `AGARTHA_REFERENCE_MODELING_OPERATOR_AGENT_ID` owns the new request. Deploy the additive schema and worker before the gateway/UI; verify an operator run before public activation.
